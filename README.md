# Real-Life Patch Notes: The Comedy Changelog

One-line software patch note for a bug in real life / human biology, written for the
[make.fun](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d)
bounty `u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d`.

## The entry

> v2.7.1: fixed a bug where the brain replayed your most embarrassing moment from 2014 at 3am instead of sleeping.

112 characters, one line. The brain ships a 3am replay of a decade-old embarrassment
instead of the sleep it was asked for — a real, recognisable bug of human biology,
filed in the terse register of a release note.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the patch note to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), then re-reads it and verifies the gate:
UTF-8 text, 1–160 characters, exactly one line.
